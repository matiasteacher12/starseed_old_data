# 스타시드 구 한국판 뷰어 데이터

[뷰어](https://github.com/matiasteacher12/starseed_old_viewer)가 실제 참조하는 애셋만 배포합니다.
메인 스토리 94화 및 인스타시드용 998개 논리 참조, 920개 고유 SHA-256 객체입니다.
제작용 애셋 전체, 원본 APK/게임 파일, 미사용 보관 객체, 사용자 설정/저장 상태는 포함하지 않습니다.
원본 번들 내부에서 종속성을 공유하는 항목은 번들 단위로 보존합니다.

바이너리 데이터는 `assets-v0.7.6` Release의 분할 ZIP에 있습니다. ZIP 파일은 Git 이력에 넣지 않습니다.
`install.json`은 각 ZIP의 크기·SHA-256·포함 객체를, `content.json`은 앱의 논리 참조를 고정합니다.
작은 시작 UI 번들은 첫 실행을 위해 뷰어 저장소에 포함됩니다. 나머지는 앱이 자동으로 설치합니다.
원본 파일명/논리 경로/버전/해시는 `source-metadata.json`에 보존합니다. 확인되지 않은 제작자는 추정하지 않습니다.
원본 게임 애셋의 권리는 해당 권리자에게 있습니다.
