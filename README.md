# 스타시드 구 한국판 뷰어 데이터

[뷰어](https://github.com/matiasteacher12/starseed_old_viewer)가 실제 참조하는 애셋만 배포합니다.
데이트 296편을 포함한 스토리 1,061항목과 인스타시드용 4798개 논리 참조, 4719개 고유 SHA-256 객체입니다. 메시지는 74명·370개 대화이며 프로필은 82개입니다.
제작용 애셋 전체, 원본 APK/게임 파일, 미사용 보관 객체, 사용자 설정/저장 상태는 포함하지 않습니다.
원본 번들 내부에서 종속성을 공유하는 항목은 번들 단위로 보존합니다.

바이너리 데이터는 `assets-v0.7.6`, `assets-v0.9.1`, `assets-v0.9.2` Release의 분할 ZIP에 있습니다. 기존 데이터는 재사용하고 현재 설치에 없는 추가 묶음만 내려받습니다. 0.9.2 추가 묶음은 약 12.2 MB입니다. ZIP 파일은 Git 이력에 넣지 않습니다.
`install.json`은 각 ZIP의 크기·SHA-256·포함 객체를, `content.json`은 앱의 논리 참조를 고정합니다.
작은 시작 UI 번들은 첫 실행을 위해 뷰어 저장소에 포함됩니다. 나머지는 앱이 자동으로 설치합니다.
원본 파일명/논리 경로/버전/해시는 `source-metadata.json`에 보존합니다. 확인되지 않은 제작자는 추정하지 않습니다.
원본 게임 애셋의 권리는 해당 권리자에게 있습니다.

앱 0.8.0부터 첫 다운로드용 시작 영상은 뷰어 저장소의 Bootstrap에 포함됩니다. install.json의 startupMovie로 크기/SHA-256을 고정하며 본편 Release 파일은 변경하지 않습니다.
